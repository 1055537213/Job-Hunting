# BOSS 直聘职位数据接入研究

研究日期：2026-07-24

## 结论

第一版采用用户介入的半自动只读接入：Agent 生成官方搜索入口和筛选建议，候选人在正常 BOSS 直聘页面查看职位后，主动复制可见职位内容或提供手动导出文件，系统在本地解析、去重和标准化。自动登录、接管用户会话、爬虫、插件、拟人程序和绕过访问限制都不作为实现依赖。

## 依据

- BOSS 直聘[用户协议](https://about.zhipin.com/agreement)要求用户通过平台使用服务，并明确禁止未经许可通过第三方工具或运营平台获取平台信息，包括使用插件、外挂、爬虫、蜘蛛、拟人程序等非正常浏览手段。
- 同一协议要求账号由本人使用，不能将账号告知或提供给第三方代用；违反平台流程、功能限制或运营策略可能导致账号被限制或终止。
- 公开职位搜索页曾展示城市、关键词/职位、经验、学历、薪资、融资阶段、公司规模及职位卡片等可见字段，但未登录访问深度、登录提示和页面结构都可能变化，因此不把匿名页面抓取当作稳定接口。

## 设计影响

- 搜索规划器输出 BOSS 官方搜索链接、关键词和筛选条件，而不是直接调用隐藏接口。
- 导入器接受候选人主动提供的文本、截图或手动导出文件，并保留来源 URL 与获取时间。
- 解析失败、字段缺失或职位已过期时要标记不确定性，不把结果伪装成完整职位全集。
- 后续只有在取得官方 API、合作数据源或明确授权后，才考虑增加正式平台连接器。

这份研究记录的是产品技术边界，不构成法律意见；正式上线前仍应复核当时有效的平台规则和适用法律。

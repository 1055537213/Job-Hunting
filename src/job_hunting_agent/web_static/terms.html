Job Hunting Agent

服务条款

本页面是产品部署基线文本，正式上线前应由实际运营主体结合所在地区法律、收费方式和模型供应商条款审核并替换。

服务范围

系统提供求职资料整理、职位分析、项目证据管理、检索和简历生成辅助。模型输出可能不准确，用户应在使用前审核。

用户责任

用户应确保上传材料具有合法来源，不得上传他人凭据、恶意文件或侵犯隐私、版权及其他权利的内容。

账号与费用

账号应由本人使用并妥善保管密码。模型调用可按实际 Token 计费，具体价格、充值和退款规则以上线时页面展示为准。

服务变更

影响用户权利的重要条款变更应更新版本并重新取得同意。用户可在个人中心导出数据或申请注销账号。

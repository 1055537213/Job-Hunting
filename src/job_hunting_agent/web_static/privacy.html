Job Hunting Agent

隐私政策

本页面是产品部署基线文本，正式上线前应由实际运营主体根据部署位置、模型供应商和数据处理活动审核并替换。

收集的数据

系统处理账号邮箱、登录安全信息、候选人档案、职位、项目、简历、对话、用量和余额流水。密码和一次性链接只保存不可逆哈希。

处理目的

数据用于身份认证、求职材料分析、知识检索、结果生成、计费、安全防护和故障排查，不应用于与本服务无关的用途。

保存与删除

用户可导出本人数据。注销后求职内容会被删除，账号身份会匿名化；依法或对账所需的余额和交易事实按要求保留。

第三方处理

模型、邮件、对象存储和支付供应商可能处理完成服务所需的数据。正式运营方应在此列明供应商、区域、目的和保存期限。

安全与联系

系统采用账号隔离、访问控制、加密传输、恶意文件扫描和审计措施。正式上线前应补充运营主体及隐私联系渠道。
